# Lucide icons

`info.svg`, `terminal.svg`, and `ellipsis.svg` are exports of the official Lucide instances in the approved puipui Figma design (file `spwA1eEgycGIK1TtjHZ45R`, panel `15:198`). The PDFs are vector conversions of those exports for AppKit, generated with `rsvg-convert -f pdf`.

Render at 16×16pt using template tint. The SVG geometry is unchanged.

Source: https://lucide.dev/icons/ · License: ISC (see LICENSE).

`app-mark.pdf` is the original resting guinea pig symbol, not a Lucide glyph. It is generated from `Resources/AppIconConcepts/guinea-pig-c.svg` and rendered at 18×18pt as the menu bar template image.
